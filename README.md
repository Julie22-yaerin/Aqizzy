# The Lyceum - Nền Tảng Huấn Luyện Trí Tuệ Nghịch Cảnh (AQ) cho Học Sinh Cấp 2

> **The Lyceum** là nền tảng web giáo dục ứng dụng trí tuệ nhân tạo (AI) giúp rèn luyện và nâng cao chỉ số vượt khó **AQ (Adversity Quotient)** cho học sinh Trung học Cơ sở Việt Nam (Cấp 2 - Lớp 6 đến 9) thông qua mô hình tâm lý học ứng dụng **CORE (Control - Ownership - Reach - Endurance)** trong các tình huống mô phỏng nhập vai chân thực của đời sống học đường.

---

## 🌟 Mô Hình CORE & 4 Tình Huống Học Đường Việt Nam

### 1. **CONTROL (C) - "The 9 PM Sunday Zalo Panic" (Cơn hoảng loạn Zalo lúc 9h tối Chủ Nhật)**
- **Bối cảnh:** 21:00 Chủ Nhật, nhóm chat Zalo môn Khoa học Tự nhiên (KHTN) nổ tung khi cô giáo thông báo đổi đề tài thuyết trình sáng mai từ tế bào sang hệ hô hấp. Tiệm tạp hóa đã đóng cửa, cả nhóm hoảng loạn.
- **NPCs:** 
  - Minh Khang (👦🏻): Hoảng sợ, đòi thức trắng đêm nặn đất sét dù không có đồ nghề.
  - Linh Chi (👧🏻): Bất cần, cay cú cô giáo, dọa bỏ cuộc chấp nhận điểm 0.
- **Thước đo CORE:** Tập trung vào điều mình **có thể kiểm soát** ngay lúc này.
- **Cơ chế:** Giao diện mô phỏng Zalo Chat với AI sinh lời thoại động và chấm điểm thời gian thực.
- **Hành động High AQ:** Trấn an bạn bè, đề xuất vẽ sơ đồ giải phẫu hệ hô hấp 2D trên giấy A3/A4 có sẵn tại nhà, phân chia nhiệm vụ và sáng mai đại diện lên gặp cô giải thích lý do khách quan.

### 2. **OWNERSHIP (O) - "The Homeroom Period (Giờ Sinh Hoạt Lớp)"**
- **Bối cảnh:** Tiết sinh hoạt chiều thứ Sáu, Cô Chủ Nhiệm (Cô Mai) giận dữ vì lớp đứng bét khối (12/12) do Tổ 3 có bạn Nam bị Thầy Giám thị bắt ăn vụng và nhét rác vào hộc bàn trong giờ truy bài. Bạn là Tổ trưởng.
- **NPCs:** Cô Mai (👩🏻‍🏫 - GVCN nghiêm khắc) & Nam (👦🏽 - Thành viên vi phạm đang run sợ).
- **Thước đo CORE:** Dũng cảm nhận trách nhiệm người lãnh đạo vs Đùn đẩy, chối bỏ lỗi lầm.
- **Cơ chế:** Giao diện lớp học với bảng xanh phấn trắng, thước đo cảm xúc giáo viên và đối thoại phân nhánh.
- **Hành động High AQ:** Đứng dậy lễ phép nhận lỗi Tổ trưởng chưa sâu sát, không trút hết tội cho bạn Nam, xin cùng Nam nhận phạt trực nhật chuộc lỗi cho lớp.

### 3. **REACH (R) - "The 45-Minute Math Test Disaster (Bài kiểm tra 4 điểm)"**
- **Bối cảnh:** Nhận lại bài kiểm tra 1 tiết Toán với điểm số 4/10 đỏ chót. Nỗi sợ mẹ mắng và trượt danh hiệu Học Sinh Giỏi bủa vây.
- **Thước đo CORE:** Khoanh vùng thất bại (Compartmentalization) — không để một điểm kém cục bộ phá hủy lòng tự trọng và tương lai.
- **Cơ chế:** Giao diện vuốt thẻ kiểu Tinder (Framer Motion drag gestures).
- **Hành động:** 
  - **Vuốt Trái (Loại bỏ - Low AQ):** *"Mẹ sẽ giết mình mất"*, *"Mình dốt toán bẩm sinh rồi sẽ trượt cấp 3"*, *"Cả lớp đang cười chê mình"*, *"Cả năm học này coi như vứt đi"*.
  - **Vuốt Phải (Giữ lại - High AQ):** *"Chỉ là một bài 1 tiết, mình sẽ gỡ điểm ở bài thi Học kì"*, *"Môn Văn và Anh mình vẫn đang 9 điểm"*, *"Tối nay phải nói thật với mẹ để xin đi học kèm"*, *"Xem lại bài để biết mình sai dạng phương trình nào"*.

### 4. **ENDURANCE (E) - "The May Exam Crush (Cơn lốc mùa thi tháng Năm)"**
- **Bối cảnh:** Tháng 5. Còn 2 tuần nữa thi Học kì 2. 8 cuốn đề cương dày cộm và 5 ca học thêm/tuần từ mẹ.
- **Thước đo CORE:** Phân bổ sức lực đường dài, duy trì thể chất và tinh thần, chống kiệt sức (Burnout).
- **Cơ chế:** Dòng thời gian 7 ngày với 2 thanh tài nguyên **Năng lượng (Energy)** và **Căng thẳng (Stress)**.
- **Hành động High AQ:** Xin mẹ rút bớt 1 ca học thêm đêm để ngủ đủ 8 tiếng, chia nhỏ đề cương theo phương pháp Pomodoro, vận động tái tạo năng lượng, chấp nhận điểm 8 môn phụ để tập trung môn chính.

## 🛠️ Công Nghệ Sử Dụng (Tech Stack)

- **Frontend Framework:** Next.js 14+ (App Router), React 18, TypeScript.
- **Styling & UI:** Tailwind CSS, Lucide Icons, Canvas Confetti.
- **Animation & Gestures:** Framer Motion (vuốt thẻ Tinder, tương tác mượt mà).
- **State Management:** Zustand (với persistent client state, SSR-safe storage).
- **Backend & Database:** Supabase (PostgreSQL, Row Level Security, Realtime).
- **AI Integration:** NVIDIA AI NIM API (`meta/llama-3.1-70b-instruct`) thông qua SDK chuẩn `openai` với định dạng JSON cấu trúc duy nhất (Single-call cost-optimized output) và động cơ mô phỏng tiếng Việt dự phòng (Fallback Simulator).
- **Audio Synthesizer:** Web Audio API (âm thanh thông báo Zalo, tiếng lướt thẻ, chuông chiến thắng mà không cần file audio ngoài).

## 🚀 Hướng Dẫn Cài Đặt & Chạy Thử

### 1. Cài đặt thư viện
```bash
npm install
```

### 2. Cấu hình biến môi trường (`.env.local`)
Tạo file `.env.local` dựa trên mẫu `.env.example`:
```env
# NVIDIA NIM AI API
NVIDIA_API_KEY=your_nvidia_api_key
NVIDIA_BASE_URL=https://integrate.api.nvidia.com/v1
NVIDIA_MODEL=meta/llama-3.1-70b-instruct

# Supabase
NEXT_PUBLIC_SUPABASE_URL=https://your-project.supabase.co
NEXT_PUBLIC_SUPABASE_ANON_KEY=your-anon-key
```

### 3. Chạy môi trường phát triển (Development)
```bash
npm run dev
```
Mở trình duyệt tại [http://localhost:3000](http://localhost:3000)

### 4. Build sản phẩm (Production Build)
```bash
npm run build
npm run start
```
